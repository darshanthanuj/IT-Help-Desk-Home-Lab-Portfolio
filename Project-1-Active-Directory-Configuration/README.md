
# Project 1: Active Directory Home Lab

## Overview
This project demonstrates practical experience configuring a Windows Server environment and integrating a Windows client with an Active Directory domain in a home lab.

## Skills Demonstrated
- Windows Server configuration
- Active Directory Domain Services (AD DS)
- DNS configuration and troubleshooting
- Windows domain integration
- Basic network troubleshooting
- Technical documentation

## Project Contents
- Project documentation in Word format
- Project documentation in PDF format
- Screenshots showing configuration steps

## Learning Outcomes
Developed practical knowledge of Windows domain environments, DNS, domain joining, and basic troubleshooting.

## Environment
Windows Server and Windows client home lab.

This is a self-directed learning project created for IT Help Desk portfolio purposes.
