# Project 4 – Windows 11 Help Desk Troubleshooting

## Project Overview

This project demonstrates practical Windows 11 troubleshooting skills developed through a self-directed IT Help Desk home lab.

The project simulates common Level 1 IT support incidents and follows a structured troubleshooting methodology to investigate reported issues, perform diagnostic checks, analyse results, document findings and determine appropriate resolutions or escalation requirements.

All exercises were performed in a Windows 11 virtual machine environment using VMware Workstation.

## Project Objectives

- Develop practical Windows 11 troubleshooting skills relevant to Level 1 IT Support.
- Investigate common desktop operating system issues.
- Practise using Windows built-in diagnostic tools and commands.
- Understand user accounts, permissions and access management.
- Perform basic network, application and hardware troubleshooting.
- Understand Windows security and malware incident handling.
- Develop structured technical documentation and escalation practices.

## Troubleshooting Methodology

Each scenario follows a structured Level 1 IT support workflow:

1. **Incident Identification** – Understand the reported issue and its impact on the user.
2. **Initial Assessment** – Identify the affected device, user and relevant symptoms.
3. **Information Gathering** – Collect system information and diagnostic evidence.
4. **Troubleshooting** – Perform appropriate checks using Windows tools and commands.
5. **Analysis** – Review diagnostic results and identify potential causes.
6. **Resolution or Escalation** – Apply an appropriate authorised solution or escalate when required.
7. **Verification** – Confirm whether the issue has been resolved, where applicable.
8. **Documentation** – Record actions performed, results and supporting evidence.

## Security and Incident Escalation

The security troubleshooting scenario covers basic Microsoft Defender and Windows Firewall checks, including:

- Reviewing Microsoft Defender Protection History.
- Running a Microsoft Defender Quick Scan.
- Checking antivirus protection settings.
- Reviewing Windows Firewall status.
- Understanding suspicious links, downloads and potential malware risks.
- Following organisational incident response and escalation procedures.

No actual malware was introduced into the lab environment.
