
# Project 2: Active Directory User Account Management & IT Help Desk Workflows

## Overview
This home lab project focuses on common user administration activities and entry-level IT Help Desk workflows in an Active Directory environment.

## Objectives
- Practise user account management concepts.
- Document onboarding and account support workflows.
- Understand group membership and access permissions.
- Develop a consistent approach to routine support requests.

## Skills Demonstrated
- Active Directory users and organisational units
- User account administration and onboarding concepts
- Password reset and account-lockout support
- Security group membership
- Departmental access permissions
- Technical documentation
