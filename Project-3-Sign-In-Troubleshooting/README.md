
# Project 3: IT Help Desk – Sign-In Troubleshooting

## Overview
This project documents a structured approach to investigating a Windows domain sign-in issue in a home lab.

## Troubleshooting Approach
- Check the user's Active Directory account status.
- Review the client's network configuration.
- Check DNS resolution.
- Verify domain controller discovery.
- Analyse diagnostic results to narrow down the cause.
- Document the findings and resolution in a support-ticket style summary.

The confirmed cause and final resolution are documented in the accompanying project report.

## Skills Demonstrated
- Structured IT Help Desk troubleshooting
- Active Directory account-status checks
- Basic network configuration
- DNS and name-resolution troubleshooting
- Domain controller discovery
- Command-line diagnostics
- Technical notes and ticket-resolution documentation

## Project Files
- Word document: Detailed troubleshooting report
- PDF document: Shareable troubleshooting report
- Screenshots/: Supporting troubleshooting evidence

Refer to the Word or PDF report for the investigation, evidence and final resolution.

## Learning Outcome
Practised a systematic approach to troubleshooting: gather information, test likely causes, identify the issue and document the resolution.

## Disclaimer
This is a self-directed home lab exercise, not production enterprise support experience.
